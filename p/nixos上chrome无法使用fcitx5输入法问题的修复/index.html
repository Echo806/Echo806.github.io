NixOS上chrome无法使用fcitx5输入法问题的修复

2026-05-10

NixOS 上 Chrome 无法使用 fcitx5 输入法问题修复

环境信息

项目 配置
系统 NixOS 25.11 (x86_64-linux)
桌面 KDE Plasma 6 (Wayland)
输入法 fcitx5 + Rime (雾凇拼音)
浏览器 Google Chrome
安装 Home Manager (home.packages)

问题现象

Chrome 浏览器中可以正常浏览网页，但无法在任何输入框中切换或使用中文输入法。fcitx5 在其他应用（Kate、Firefox、终端）中工作正常。

根因分析

NixOS 的 Chrome wrapper 脚本内建了 Wayland + IME 支持，但通过条件变量控制：

# Chrome wrapper 关键逻辑（来自 $(readlink -f $(which google-chrome-stable))）
${NIXOS_OZONE_WL:+${WAYLAND_DISPLAY:+--ozone-platform-hint=auto \
--enable-features=WaylandWindowDecorations --enable-wayland-ime=true}}
条件 含义
${NIXOS_OZONE_WL:+...} 仅当设置了 NIXOS_OZONE_WL 环境变量才展开
${WAYLAND_DISPLAY:+...} 仅当 Wayland 会话存在时才展开
--ozone-platform-hint=auto 让 Chrome 自动选择原生 Wayland 渲染
--enable-wayland-ime=true 启用 Wayland IME 协议（zwp_text_input）

当 NIXOS_OZONE_WL 未设置时，Chrome 以 XWayland 模式运行，使用 XIM 协议与输入法通信。XIM 在 Wayland + fcitx5 环境下支持不完整，导致输入法失效。

NIXOS_OZONE_WL 未设置
       ↓
Chrome 以 XWayland 模式启动
       ↓
使用 XIM 协议（Wayland + fcitx5 下支持不完整）
       ↓
❌ 中文输入法无法使用

解决方案（正确做法）

在 home.nix 的 home.sessionVariables 中设置：

# home.nix
home.sessionVariables = {
  NIXOS_OZONE_WL = "1";   # 启用 Chrome/Electron Wayland IME 支持
};

NIXOS_OZONE_WL=1 ✓
       ↓
Chrome 以原生 Wayland 模式启动（--ozone-platform-hint=auto）
       ↓
使用 Wayland IME 协议（--enable-wayland-ime=true）
       ↓
✅ 中文输入法正常工作

Rebuild 后重新登录桌面（或重启），Chrome 即可使用 fcitx5 输入法。
