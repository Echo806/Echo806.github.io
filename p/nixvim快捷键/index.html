nixvim快捷键

2026-09-28

上次那版只列了我自己写的几个映射，日常能用的 Neovim 默认按键和插件按键没有展开。这次我重新对照了 x250 的 Nixvim 配置，把常用操作集中列在下面。当前这台机器运行的是 Neovim 0.12.4，LSP 表格也按这个版本的内置映射整理。

先分清来源：标成“本机映射”的才是我在配置里亲自绑定的键；“Neovim 默认”是编辑器自带的 Vim 按键；“插件默认”是 Neo-tree、Telescope、Blink 启用后提供的按键。插件默认键位可能随版本变化，在 Neo-tree 里按问号、Telescope 里按问号，能查看当前运行版本的帮助。Neovim 自带帮助可以用 :help quickref 打开，也可以查看 Neovim 快捷键索引。

表格中的 Ctrl+x 表示按住 Ctrl 再按 x；“次数”表示先输入数字再执行按键，例如 5j 向下移动五行、3dd 删除三行。Normal 是普通模式，Insert 是插入模式，Visual 是可视选择模式。

模式、前缀与本机映射

配置把 Space 设为全局 leader，等待后续按键的时间是 300 毫秒。which-key 会在按下前缀后提示可继续输入的组合。maplocalleader 也设成 Space，但目前没有配置任何局部前缀映射。

剪贴板与寄存器

当前配置设了 clipboard=unnamedplus，并安装了 Wayland 剪贴板工具。因此普通的 y、d、p 默认会和系统剪贴板联动。Neo-tree 的文件复制剪切是另一套文件路径剪贴板，与这里复制文本不是一回事。

按键或命令 操作 来源
y 后接移动命令 复制文本；例如 yy 复制整行 Neovim 默认加本机剪贴板选项
d 后接移动命令 删除文本；被删除内容会进入寄存器，也会按本机设置同步到系统剪贴板 Neovim 默认加本机剪贴板选项
p 或 P 粘贴到光标后或前；整行内容会按行粘贴 Neovim 默认加本机剪贴板选项
双引号、加号、y，例如 “+y 明确把选中文本复制到系统剪贴板 Neovim 默认
双引号、加号、p，例如 “+p 明确从系统剪贴板粘贴 Neovim 默认
双引号、字母、y，例如 “ayy 把内容复制进 a 寄存器；可替换字母名 Neovim 默认
:registers 或 :reg 查看当前寄存器里的内容 Neovim 命令
双引号、下划线、dd，例如 “_dd 删除当前行但不覆盖普通复制寄存器 Neovim 默认

不用退出 Nixvim 运行 Shell

当前配置没有给终端单独绑定快捷键。普通模式输入 :terminal 后按回车，会在 Neovim 窗口里启动交互式终端，使用 Neovim 的 shell 选项。用 :pwd 可以先查看当前工作目录。按 Ctrl+反斜杠，再按 Ctrl+n，可以从终端输入模式切回 Neovim 普通模式；按 i 或 a 可回到终端输入。输入 exit 结束 Shell。

只想运行一条命令，也可以输入 :!命令，例如 :!pwd 或 :!ls -lah。命令结束后按回车返回 Neovim。:terminal 适合连续操作，:! 适合临时执行一条命令。

命令 用途
pwd 显示当前目录
ls -lah 列出当前目录下的文件，包含隐藏文件
mkdir -p “目录” 创建目录；父目录不存在时一并创建
touch “文件” 创建空文件；文件已存在时更新时间
cp -i – “源文件” “目标目录/” 复制文件；覆盖前询问
cp -ri – “源目录” “目标目录/” 递归复制目录；覆盖前询问
mv -i – “源路径” “目标目录/” 移动文件或目录；覆盖前询问
rm -i – “文件” 删除文件前询问
rm -ri – “目录” 递归删除目录，并逐项询问
rmdir “空目录” 删除空目录；目录非空时会失败 
mkdir -p "目标目录"
touch "目标目录/新文件.md"
cp -i -- "原文件.md" "目标目录/"
mv -i -- "旧名字.md" "新名字.md"
rm -i -- "不再需要的文件.md"

命令中的双引号可以保护带空格的路径，– 表示后面的内容都是路径名。rm -ri 会逐项询问；确认删除前先检查显示的文件名。Neo-tree 的 a、A、r、y、x、p、c、m、d 则可以直接在文件树里完成新建、重命名、复制、移动和删除。
