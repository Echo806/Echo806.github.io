nixvim快捷键

2026-09-28

我把 x250 上的 Nixvim 配置翻了一遍，发现常用入口其实不多。<leader> 设成了空格，自己定义的快捷键也都在普通模式下：Space e 开关文件树，Space ff 查找文件，Space fg 搜索文本，Space fb 找已打开的缓冲区，Space fh 搜索帮助文档。普通模式按 Esc 会清除搜索高亮。按空格后可以稍等 which-key 的提示；前缀映射的等待时间是 300 毫秒。

在文件树里处理文件

打开文件树后，Enter 展开目录或打开文件，Backspace 回到上级目录，. 把选中的目录设为树根。新建文件按 a，输入以 / 结尾的路径会新建目录；A 可以直接新建目录，r 重命名。

复制和移动也不用离开树窗口：选中文件后按 y 标记复制，切到目标目录按 p 粘贴；按 x 标记移动，再到目标目录按 p。想直接指定目标路径，可以用 c 复制或 m 移动。d 会先询问确认，再删除文件；删非空目录时会递归删除，所以确认前要看清选中的路径。按 ? 可以在树窗口里查看完整的按键帮助。

配置里的 clipboard = "unnamedplus" 是 Vim 文本寄存器和系统剪贴板的联动。Neo-tree 里的 y、x、p 用的是文件树自己的剪贴板，两者别混在一起。

在 Nixvim 里运行 shell

当前配置没有给终端另设快捷键，不过 Neovim 自带终端。普通模式输入 :terminal，就会在编辑器里打开交互式 shell。x250 的登录 shell 是 Bash。终端默认从 Nvim 当前工作目录启动；不确定目录时先用 :pwd 看看。

终端里可以照常运行文件命令：

mkdir -p "目标目录"
cp -i -- "源文件" "目标目录/"
cp -ri -- "源目录" "目标目录/"
mv -i -- "源路径" "目标目录/"
rm -i -- "文件"
rm -ri -- "目录"

-i 会在覆盖或删除时询问，-- 后面的内容都按路径处理。用 rm -ri 删除目录时，命令会逐项询问；Neo-tree 的 d 则会递归删除确认过的非空目录。

按 Ctrl-\，再按 Ctrl+n，可以从终端输入模式回到 Nvim 普通模式；按 i 回到终端输入。想结束 shell 就输入 exit，想直接执行一条命令也可以用 :!pwd 或 :!ls -lah，命令结束后按回车回到编辑器。

平时在文件树里新建、重命名、复制和移动比较顺手；需要连续敲命令时用 :terminal。这样处理项目文件时不用退出 Nixvim 再开一个终端。
